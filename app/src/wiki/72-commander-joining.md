## Join War

**Join War** on the [Commander tab](app:commander) needs no package. The dialog listens for wars open to LAN on the same network for a few seconds and lists each one with the host computer name, the season and the player count. **Join** on a row joins that war, and **Scan Again** listens once more.

A war on another network doesn't show in that list. Type the address the host sent under **Join by Address**, with the port, such as `203.0.113.7:17494`, and the invite code beside it, then **Find Wars**. The wars that answer join the list. A war on the same network or the same VPN needs no code.

## After joining

Joining selects the war for the next **Play**, and the war gets a tab in the row under the war list, beside **This PC**, with the host computer name on hover. That tab shows the war screens of the host in view-only mode: the map, the events, the feed, the players and the statistics, with **Overview** in place of the orders. The × on the tab removes the war from the list, while the war save stays in [Saves](app:saves).

## Playing a joined war

A joined war plays like a hosted one ([Playing a war](wiki:commander-playing)): a separate Sandbox save on this PC, a separate matchmaking pool, and Obsidian open while playing. The host PC has to be on with Obsidian open, or the game shows the war as offline.

When the host makes a **New Code**, the old code stops working and the war shows as offline. Join again with the new code: the war keeps the same save.
