[Settings](app:settings) has three subtabs:

| Subtab | What it holds |
|---|---|
| System | The game folder and the build check, patches from other tools, Play, the language, updates, the data folder and the problem report |
| Updates | The installed version, new versions, and what each version changed |
| Theme | Colors, interface scale, text size and animations |

App settings save at once. The **?** beside a heading opens the guide for that part. [How Obsidian works](wiki:how-obsidian-works#updating-obsidian) covers updates, and [where the files are](wiki:how-obsidian-works#where-your-files-are) lists the folders Obsidian uses.
