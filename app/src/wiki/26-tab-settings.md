[Settings](app:settings) has three subtabs:

| Subtab | Groups |
|---|---|
| System | **Game**: the game folder and the [build check](wiki:deploy-and-purge#the-build-check). **Other patches**: patches from other tools, when there are any. **General**: **Ask before playing vanilla**, **App language** and **When a new version is out**. **Controller**. **Data folder**. **Save backups**. **Problem report** |
| Updates | The installed version, new versions, and what each version changed |
| Theme | **Appearance**: colors, interface scale and text size. **Motion**: animations |

App settings save at once. The **?** beside a heading opens the guide for that part. [How Obsidian works](wiki:how-obsidian-works#updating-obsidian) covers updates, and [where the files are](wiki:how-obsidian-works#where-your-files-are) lists the folders Obsidian uses.

**Problem report** copies the versions, the mods that are on and the end of the game log, for a bug report ([Asking for help](wiki:troubleshooting#asking-for-help)).

## Controller

Obsidian works with a controller as well as a mouse. Moving the left stick shows a cursor, and the cursor stays until the mouse moves again. While the controller is in use, the buttons it takes show their pictures beside them.

| Button | Does |
|---|---|
| Left stick | Moves the cursor |
| Right stick | Scrolls the list or page under the cursor |
| A (Xbox), Cross (PlayStation), B (Nintendo) | Clicks what the cursor points at |
| B (Xbox), Circle (PlayStation), A (Nintendo) | Goes back: closes a menu or dialog, or leaves a mod page or a save |
| Y (Xbox), Triangle (PlayStation), X (Nintendo) | Play |
| Start (Xbox), Options (PlayStation), + (Nintendo), Menu (Steam Deck) | Opens the choice of war and save, when there is one |
| Triggers | The previous and next main tab |
| Bumpers | The previous and next tab of the page or dialog |

The first touch of the controller only shows the cursor, so nothing is clicked by accident.

**Button pictures** picks the pictures shown: **Auto**, **Xbox**, **PlayStation** or **Nintendo**. **Auto** shows those of the controller in use, Steam Deck buttons included. A controller can reach Obsidian as another kind, a PlayStation controller through Steam Input for example, and then shows Xbox pictures: pick the right set by hand. **Cursor speed** sets how fast the left stick moves the cursor.

Obsidian sees a controller only while the window is in front, and only after the first button press. The button pictures are from the Input Prompts pack by Kenney (kenney.nl).
