## 导入 {#importing}

把模组文件夹或 `.zip` 文件拖到[模组](app:mods)标签页的模组列表上，或点击列表上方的绿色**添加**按钮并选择**导入 .zip** 或**导入文件夹**。可以一次导入多个文件，通知会说明每个文件的结果。[商店](app:store)无需手动下载即可安装模组。

Obsidian 会把模组复制到库中，所以下载的文件之后可以删除。在下次部署之前，导入不会改变游戏中的任何内容。

### 为 Obsidian 制作的模组 {#mods-made-for-obsidian}

为 Obsidian 制作的模组在文件夹或压缩包顶层有一个 `obsidian.json` 文件。Obsidian 从中读取名称、版本、选项和按键，并显示在右侧面板中。

### 旧式模组 {#older-mods}

如今分享的大多数 HD1 模组会替换整个游戏资源包，文件名类似 `9e13b2414b41b842`。Obsidian 同样可以导入它们。它会把模组中的每个资源包与游戏中的资源包比较，只保留模组真正改动的资源，因此两个改动不同内容的旧式模组可以一起运行。

有些旧式模组提供的是 `.patch_0` 或 `.patch_1` 文件，文件名类似 `9e13b2414b41b842.patch_0`，游戏会在对应的资源包之上读取它们。Obsidian 也能导入这些文件，无需手动改名为下一个空闲编号。仅包含 ReShade 预设（`ReShadePreset.ini`）的模组不是游戏模组：它需要游戏文件夹中装有 ReShade，导入时会提示这一点。

旧式模组以**未指定**作用范围导入，因为 Obsidian 无法判断它们在共享游戏中改动了什么。它们作为客户端模组运行，所以从不会让玩家进不了房间，也无法在任务中途关闭（[作用范围](wiki:scopes)）。只改动音效库的旧式模组会以**客户端**模组导入，因为声音的改动只留在一台电脑上。

另一个模组的补丁不会附带那个模组本身。请把两者都导入，并把补丁放在列表中更靠下的位置。注意补丁是为哪个版本制作的：两者共有的文件来自补丁，所以为旧版本制作的补丁会把这些文件恢复到那个版本。

> [!NOTE]
> 比较资源包需要原始游戏文件，所以当它们不同时导入会停止。通常是手动复制到游戏文件夹的模组导致的：在 Steam 中验证游戏文件完整性后重新导入。

## 更新 {#updating}

用同样的方式导入新版本。相同 id 的模组会替换库中的模组，通知会显示新旧版本号。选项值和按键会保留，作者更改了类型的选项除外。

### 通过 GitHub {#from-github}

模组可以指定一个 GitHub 仓库。Obsidian 会在启动时向 GitHub 查询这些模组的新版本（过去六小时内已查询过则跳过），也可以手动查询：

- **全部检查更新**是[模组](app:mods)标签页顶部的一个图标，会查询所有此类模组。
- 列表底部栏中的**检查更新**会查询已勾选的模组。勾选文件夹的复选框会勾选其中所有模组，列表顶部的复选框会勾选全部模组。

有新版本的模组会在版本列中以金色显示新版本号，并在模组详情中显示**更新到**。点击任一处会显示新版本和更新日志链接，然后要求确认。模组标签页顶部带数字的金色按钮会一次安装所有待更新的模组。只会提供版本更高的稳定版，未经点击不会安装任何内容。之后请部署，让新版本进入游戏。

这类模组详情中的版本标签页按渠道列出所有发布版本及各自的更改，并可以安装其中任何一个，包括较旧的版本（[渠道](wiki:sharing#channels)）。

## 移除 {#removing}

右键点击模组并选择**移除**，或使用模组详情中关闭按钮下方的垃圾桶图标。要移除多个模组，勾选它们后使用列表底部栏中的**移除**。

## Obsidian Kit {#obsidian-kit}

Obsidian 自带三个模组，位于列表顶部的 **Obsidian Kit** 文件夹中：Obsidian API、[Obsidian Trainer](wiki:trainer) 和 Obsidian Patches。Obsidian Patches 默认启用，并开启了大部分修复，另外两个在手动启用之前保持停用。

它们和其他模组一样：可以启用和停用、可以移除，也会通过 GitHub 更新。该文件夹默认锁定，所以位置固定。点击锁图标即可解锁，之后模组可以移动，文件夹也可以重命名或删除。被移除的 Kit 模组可以从[商店](app:store)顶部的 Obsidian Kit 一栏重新安装。

## 依赖 {#dependencies}

有些模组需要其他模组才能运行。右侧面板中的**依赖**标签页显示一个模组需要什么，以及哪些模组需要它。启用一个模组会同时启用它需要的模组，停用它则会停用需要它的模组。当模组需要库中缺少的模组时，标签页会提示，该模组会保持停用，直到补上所需的模组。

## 图片 {#pictures}

模组可以附带一张方形图片。要换一张，在右侧面板中打开模组并点击图片。配置也用同样的方式设置图片。
