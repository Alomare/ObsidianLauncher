[模组](app:mods)标签页就是模组库：Obsidian 知道的所有模组按加载顺序排列，并显示当前配置启用了哪些。

## 顶行 {#the-top-row}

| 控件 | 作用 |
|---|---|
| 配置按钮 | 显示当前[配置](wiki:profiles)，可以切换到其他配置或打开**管理配置** |
| **排序模组**图标 | 按模组的请求排列列表（[排序模组](wiki:load-order#sort-mods)） |
| **全部检查更新**图标 | 向 GitHub 查询所有指定了仓库的模组的新版本（[更新](wiki:adding-mods#updating)） |
| **新建文件夹**图标 | 在列表中新建文件夹（[文件夹](wiki:load-order#folders)） |
| **添加** | 导入 `.zip` 或文件夹，或打开[商店](app:store) |
| 带数字的金色按钮 | 发现更新时出现，点击安装全部更新 |
| 搜索框 | 只显示名称、描述、id 或作者包含所输入文字的模组 |
| **清除**图标 | 从游戏中移除所有 Obsidian 文件（[清除](wiki:deploy-and-purge#purge)） |
| **部署**图标 | 把已启用的模组放进游戏，有待处理的更改时变为绿色（[部署](wiki:deploy-and-purge#deploy)） |

## 列表 {#the-list}

每行包含复选框、加载顺序中的位置、开关、模组、大小、上次部署放进游戏的内容、版本和[作用范围](wiki:scopes)。右键点击表头可以显示或隐藏 **#**、**大小**、**已部署**和**版本**列。

- 开关在当前[配置](wiki:profiles)中启用或停用模组。在**部署**之前，任何更改都不会进入游戏。
- 拖动行可以改变其在[加载顺序](wiki:load-order)中的位置，文件夹用于分组。
- 名称旁的警告图标表示该模组与另一个模组改动了相同的文件；点击可查看是哪个。
- 金色版本号表示发现了更新的版本；点击即可安装。
- 勾选模组后，底部会出现一栏，可以启用或停用、检查更新或移除它们。勾选状态下的模组的开关会同时启用或停用所有已勾选的模组。

列表中的快捷键（不在搜索框中、且没有打开对话框或菜单时）：

| 按键 | 作用 |
|---|---|
| Ctrl+A | 勾选列表中显示的所有模组（应用搜索后的结果）；再按一次取消勾选 |
| Ctrl+C | 把已勾选的模组或当前打开的模组复制为名称和版本的列表 |
| Ctrl+V | 按名称或 id 勾选粘贴的列表中提到的模组；粘贴文件路径会导入这些模组 |
| Ctrl+F | 跳到搜索框 |
| Alt+上、Alt+下 | 移动获得焦点的模组或文件夹 |

右键点击行或文件夹会打开包含其他所有操作的菜单。

也可以把模组拖放到列表上。[添加模组](wiki:adding-mods)介绍了 Obsidian 能读取的格式。

## 模组详情 {#the-details-of-a-mod}

点击模组会在右侧打开详情：

| 标签页 | 显示内容 |
|---|---|
| 关于 | 描述、作者和链接 |
| 版本 | GitHub 上的发布版本（按渠道），并可切换到其中任意一个 |
| 选项 | 模组的设置，保存在配置中。有些模组还会在游戏暂停菜单的 **Mods** 下显示设置，在那里更改的值会在游戏关闭后回到此标签页 |
| 按键 | 模组的按键和手柄输入。**更改绑定**会打开一张表，为每个操作设置新的按键或鼠标按钮、手柄输入（同时按住一到四个按钮）以及输入模式 |
| 文件 | 模组的文件，以及与其他模组的冲突 |
| 依赖 | 此模组需要的模组，以及需要此模组的模组 |
