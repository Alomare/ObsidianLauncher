[设置](app:settings)有三个子标签页：

| 子标签页 | 分组 |
|---|---|
| 系统 | **游戏**：游戏文件夹和[版本检查](wiki:deploy-and-purge#the-build-check)。**其他补丁**：其他工具的补丁（如有）。**常规**：**开始原版游戏前询问**、**应用语言**和**有新版本时**。**手柄**。**数据文件夹**。**存档备份**。**问题报告** |
| 更新 | 已安装的版本、新版本以及每个版本的更改 |
| 主题 | **外观**：颜色、界面缩放和文字大小。**动效**：动画 |

应用设置会立即保存。标题旁的 **?** 会打开该部分的指南。[Obsidian 的工作方式](wiki:how-obsidian-works#updating-obsidian)介绍了更新，[文件位置](wiki:how-obsidian-works#where-your-files-are)列出了 Obsidian 使用的文件夹。

**问题报告**会复制版本号、已启用的模组和游戏日志的末尾，用于提交错误报告（[寻求帮助](wiki:troubleshooting#asking-for-help)）。

## 手柄 {#controller}

Obsidian 既可以用鼠标，也可以用手柄操作。移动左摇杆会显示光标，光标会一直显示到鼠标再次移动。使用手柄时，界面按钮旁会显示对应手柄按键的图标。

| 按键 | 作用 |
|---|---|
| 左摇杆 | 移动光标 |
| 右摇杆 | 滚动光标下的列表或页面 |
| A（Xbox）、Cross（PlayStation）、B（Nintendo） | 点击光标指向的内容 |
| B（Xbox）、Circle（PlayStation）、A（Nintendo） | 返回：关闭菜单或对话框，或离开模组页面或存档 |
| Y（Xbox）、Triangle（PlayStation）、X（Nintendo） | 开始游戏 |
| Start（Xbox）、Options（PlayStation）、+（Nintendo）、Menu（Steam Deck） | 有可选项时，打开战争和存档选择 |
| 扳机键 | 上一个和下一个主标签页 |
| 肩键 | 页面或对话框中的上一个和下一个标签页 |

第一次触碰手柄只会显示光标，以免误点。

**按键图标**选择显示哪套图标：**自动**、**Xbox**、**PlayStation** 或 **Nintendo**。**自动**显示正在使用的手柄的图标，包括 Steam Deck 的按键。手柄可能以另一种类型出现在 Obsidian 中，例如通过 Steam Input 连接的 PlayStation 手柄，此时会显示 Xbox 图标：请手动选择正确的图标组。**光标速度**设置左摇杆移动光标的快慢。

只有窗口位于前台时，并且在第一次按下按键之后，Obsidian 才能识别手柄。按键图标来自 Kenney 的 Input Prompts 素材包（kenney.nl）。
