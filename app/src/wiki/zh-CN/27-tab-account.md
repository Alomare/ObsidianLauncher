[账户](app:account)标签页（顶部栏右端的人像图标）把 Obsidian 与 GitHub 账号关联起来。Obsidian 的其他所有功能无需账号也能使用。图标上的对勾表示已登录账号。

## GitHub {#github}

**使用 GitHub 登录**会显示一个代码并打开 GitHub 登录页面。在那里输入代码即可完成登录。Obsidian 永远不会看到 GitHub 密码。

**权限**列表显示 GitHub 允许 Obsidian 做什么，**允许**会向 GitHub 申请另一种权限：

| 权限 | 用途 |
|---|---|
| 公开仓库权限 | 报告问题、回复报告、给模组加星标以及向商店提交模组 |
| Gist 权限 | 多台电脑之间的同步 |
| 私有仓库权限 | 该账号可读取的私有仓库中的抢先体验模组。GitHub 授予的是对该账号能访问的所有仓库的读写权限，所以只有在这里允许后 Obsidian 才会申请 |

**退出登录**会让 Obsidian 在这台电脑上忘记该账号。在通过**在 GitHub 上撤销**撤销之前，GitHub 上的权限仍然有效。

## 报告 {#reports}

在[商店](wiki:tab-store)模组页面上用**报告问题**发送的问题会列在这里，显示模组、状态（未解决、已关闭或已修复）和日期。数字表示有新回复。点击某个报告会显示对话，可以在其中撰写并发送回复。**在 GitHub 上打开**会在浏览器中打开该 issue，**从列表中移除**会把它从此列表中移除，但不会在 GitHub 上关闭它。

## 同步 {#sync}

同步让多台电脑上的配置和外观设置保持一致。它把这些内容保存在 GitHub 账号中的一个秘密 gist 里，因此需要 Gist 权限。

- **上传**把这台电脑上的配置和外观设置保存到 gist。
- **获取**在另一台电脑上读取它们。同名配置会被替换，配置中用到但库中缺少的模组会从其 GitHub 仓库安装。没有仓库的模组需要手动添加，Obsidian 会列出它们的名称。
- **打开 gist** 会在 GitHub 上显示保存的文件。
