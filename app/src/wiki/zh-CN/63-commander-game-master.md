## 战争界面 {#the-war-screen}

从战争列表打开一场战争会显示战争界面。顶部栏包含战争名称以及赛季和状态、战争时钟、**Share**、**War Settings**（齿轮）、**More** 菜单，以及该战争被设为**开始游戏**要启动的战争时显示的 **Selected**。下方的银河地图根据游戏绘制战争地图，每条战线使用敌人的颜色，地图下方的条带显示每条战线推进到哪里。地图上的 Events 面板列出正在进行的防御和进攻及其剩余时间。

侧边面板有四个标签页，也可以用数字键 1 到 4 切换：**Command**、**Feed**、**Players** 和 **Statistics**。按 Esc 清除地图上的选择。

## 时钟和速度 {#clock-and-speed}

战争服务器运行且时钟未暂停时，战争时间会流逝。时钟旁的环形按钮用于暂停和继续，空格键也可以。时钟暂停时，事件倒计时也会停止。速度按钮设置每个现实秒流逝多少战争时间，从 0.5× 到 10×。敌人压力、事件时长和战争导演都遵循战争时间。主机电脑上的 Obsidian 关闭时，战争时间不会流逝，下次启动时战争从停下的地方继续。

## 命令 {#orders}

点击条带上的战线、地图上的区域或中间的超级地球，会在 **Command** 标签页中打开对应的命令。每条命令都会显示在 Feed 中，并标记为 GM。

| 命令 | 作用 |
|---|---|
| Enemy Push | 敌人夺回一个区域 |
| Liberate | 地狱潜兵夺取一个区域 |
| Move Front Here | 把所选区域设为前线 |
| Front Points | 用滑块或数字把战线点数设为任意值 |
| Start Defense | 在战线当前所在区域发起防御，或用 **Start Defense Here** 在所选区域发起，时长和目标在按钮上方设置。一次只能进行一场防御 |
| Start Attack | 对敌人母星发起进攻，时长和目标在按钮上方设置 |
| Introduce Front | 让尚未加入战争的战线加入，并保留它原有的点数 |
| Remove Front | 把战线移出战争。其上进行中的事件结束，玩家不再看到它，点数会保留到 **Introduce Front** |
| Mark Defeated | 把这条战线上的敌人算作被击败。所有战线都被击败时，赛季胜利 |
| Reopen Front | 让被击败的敌人回来，占据最后两个区域 |

超级地球只有一条命令：针对面板中所选战线的防御。选中一个进行中的事件会显示进度、设置事件点数，或用 **End as Success** 或 **End as Failure** 立即结束该事件。

## 赛季 {#seasons}

所有战线都被击败时赛季胜利，超级地球陷落时赛季失败。无论哪种情况，战争都会停止，直到 **New Season**，玩家下次进入游戏时会播放回顾和赛季结束画面。**Command** 标签页中的 **End Season** 会以胜利或失败结束当前赛季。**New Season** 从起始点数开始下一个赛季：统计数据重新开始，玩家和历史记录保留。

## Feed、Players 和 Statistics {#feed-players-and-statistics}

**Feed** 按时间倒序列出发生的一切：任务、得失的区域、事件、新玩家和命令。**Players** 列出所有玩过这场战争的人、当前在线的人、每个人最后一次出现的时间以及各自玩了多少场任务。**Statistics** 按战线汇总本赛季的数据（任务和成功率、星球、击杀和命中率、死亡和误杀），Front Progress 图表跟踪每条战线在最近一天、最近一周或整场战争中的进展。
