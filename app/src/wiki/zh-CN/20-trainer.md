Obsidian Trainer 是一个游戏内菜单，可以调整角色、武器、战略配备、敌人、任务和游戏数据。它随 Obsidian 提供，默认停用。

## 启用 {#turning-it-on}

在模组列表中启用 **Obsidian 修改器** 并部署。Trainer 所依赖的模组 Obsidian API 会一起启用。在游戏中按 **F6** 打开菜单，修改器的页面位于左侧的 **Obsidian 修改器** 文件夹中。窗口和按键来自 Obsidian API，所以其他模组的页面也会显示在那里，每个模组一个文件夹，在 Obsidian API 的按键标签页中可以更改该按键。

| 按键 | 作用 |
|---|---|
| 方向键或 W A S D | 移动，以及更改数值 |
| Enter 或 E | 选择，或输入数字 |
| Shift 加左或右 | 一次以十步更改数字 |
| Tab | 筛选列表 |
| R | 重置所选数值 |
| Esc 或 Q | 返回，以及关闭 |

菜单底部会以键帽样式显示这些按键。正在输入的行会就地显示文字，战略配备代码行接受方向键或 W A S D，Backspace 删除一步。菜单也可以用鼠标操作，使用系统的普通光标：

| 鼠标 | 作用 |
|---|---|
| 指向某行 | 选中该行 |
| 点击某行 | 使用该行 |
| 点击 `<` 或 `>` | 更改数值，按住可连续更改 |
| 点击数字 | 输入数值 |
| 点击行末的箭头 | 数值改变后，将其重置 |
| 滚轮或侧边滚动条 | 滚动列表 |
| 右键 | 返回 |
| 标题栏 | 拖动以移动窗口 |
| 右下角 | 拖动以调整窗口大小 |

窗口会在上次关闭的位置以相同大小打开。在列表中，按 Enter 或点击可以展开和折叠文件夹，每个文件夹会保持上次的状态。

菜单打开时角色无法行动，游戏切换画面时（例如任务开始时）菜单会自动关闭。手柄可以在菜单中导航，但只有 F6 能打开菜单。

## 菜单内容 {#what-is-in-it}

- **玩家**：无敌模式、无限冲刺、速度、传送、重生，以及已拥有的头盔、护甲和披风。
- **武器**：无限弹药、瞬间装填、补给，玩家手持的每把武器的射速、伤害、弹匣、装填、散布和穿甲，以及基础游戏或已拥有 DLC 中的任意武器、背包或特长，并带所选升级。
- **战略配备**：无冷却、无限使用次数、即时呼叫、无视禁用战略配备区域，在光标处投放基础游戏或已拥有 DLC 中的任意战略配备，以及真正的信标，包括增援。**新战略配备** 以游戏中的某个战略配备为基础创建新战略配备：名称、代码、图标、冷却、使用次数和呼叫时间，以及落地时发生什么。其他玩家看到的是作为基础的战略配备，新战略配备会在下次启动时恢复。
- **载具**：正在驾驶的载具的速度、转向、护甲、无伤以及外骨骼火箭无限，另外还有修理和补给。
- **机器人**：由本机操控的地狱潜兵，可以占用 HUD 位置，或在超过四名玩家时作为单纯的身体出现。可以对所有机器人或单个机器人下令：跟随玩家、原地待命、走到光标处、来到玩家身边、战斗、面向光标、射击、投掷、装填、像玩家一样输入战略配备代码并把信标扔到光标处、呼叫战略配备，还可以给它们武器、背包、特长和战略配备。仅限主机，且仅在任务中。
- **生成**：在原地生成弹药、补给箱和拾取物，在光标处生成信标。
- **敌人**：停止生成、冻结、致盲或击晕敌人，消灭敌人，生成更多敌人，以及设置遭遇战和巡逻的压力。
- **任务**：目标列表、完成目标、保护车队和护送对象、快速撤离、跳过等待、在任何任务中使用 Proving Grounds 修正、房间中的玩家、研究样本，以及从舰船发起任意类型的自定义任务，这些任务给予经验值和样本，且不影响战役。
- **世界**：游戏速度、镜头、HUD、雾、时间和重力，以及声音：音量，还有 **原声带** 页面，可以播放当前画面拥有的任意音乐曲目、静音或暂停，并把音乐交还给游戏。
- **编辑器**：每种武器、手雷、背包、战略配备、哨戒炮、地雷、打击、载具、敌人和状态效果的数值。
- **控制台**：开发者命令。
- **修改记录**：所有已开启或已编辑的内容，并可一次全部撤销。

选中某个选项时，菜单底部会显示它的说明。地图上的敌人（包括尸体）达到 64 个时会停止生成，因为远多于此可能导致游戏崩溃。只有主机能执行的操作在选择时会提示。

## 它不做什么 {#what-it-doesn-t-do}

- **不修改进度**。Trainer 的任何页面都不会写入存档。开启它时完成任务所获得的东西照常计入。[防护](wiki:guardrails)可以让某次启动不计入。
- **不提供玩家未拥有的 DLC**。列表显示全部基础游戏内容、通过游戏解锁的内容以及已拥有的 DLC。物品只在当次任务中有效，所以不会加入存档。
- **不改变共享战争**。向银河战争上报的命令会被拒绝，结果仍被阻止（[银河战争](wiki:galactic-war)）。

> [!WARNING]
> 游戏有防篡改检查，触发后会让玩家断开网络直到游戏重启。Obsidian Trainer 只以游戏自身的方式修改受保护的数值，所以不应触发它。其他工具和手写脚本则可能触发。

## 与他人一起游戏 {#playing-with-others}

Trainer 是会话模组，所以在公开房间中，所有人都必须运行相同的模组或允许会话模组（[联机游戏](wiki:multiplayer)）。当有不满足条件的玩家加入时，所有更改都会撤销，Trainer 页面会关闭，直到该玩家离开，之后更改会恢复。在仅限好友或私人房间中，Trainer 始终运行。编辑器中的数值和两行伤害设置在每位玩家自己的游戏中运行，所以所有人使用相同数值时效果最好。

有两项功能需要房间中只有一名玩家：给予激光瞄准器，因为其他玩家的游戏会在未经设置的情况下运行它；以及控制台中的 `spawn_enemy`，因为它只在一个游戏中加载资源包。

## 保留更改 {#keeping-changes}

更改会持续到游戏关闭。在**修改记录**中，**保留修改供下次启动**会保存编辑器的修改，只要该模组的 **保留已保存的修改** 选项开启，这些修改就会在每次启动时恢复。
