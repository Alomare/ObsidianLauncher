Obsidian Trainer 是一个游戏内菜单，可以修改角色、武器、战略配备、敌人、任务和游戏数据。它随 Obsidian 提供，默认关闭。

## 启用 {#turning-it-on}

在模组列表中启用 **Obsidian 修改器** 并部署。它所依赖的 Obsidian API 会一同启用。在游戏中，**F6** 会打开菜单，修改器的页面位于左侧的 **Obsidian Trainer** 文件夹中。窗口和按键属于 Obsidian API，因此其他模组的页面也会显示在这里，每个模组各占一个文件夹。在 Obsidian API 的“按键”标签页中可以更改按键。

| 按键 | 作用 |
|---|---|
| 方向键或 W A S D | 移动、更改数值 |
| Enter 或 E | 选择或输入数字 |
| Shift 加左右方向键 | 每次更改十步 |
| Tab | 筛选列表 |
| R | 重置所选数值 |
| Esc 或 Q | 返回、关闭 |

菜单底部会以键帽图标显示这些按键。正在输入的行会直接在行内显示文字。战略配备代码行接受方向键或 W A S D，按 Backspace 删除最后一个方向。

菜单也可以用鼠标操作，使用系统的普通光标。

| 鼠标 | 作用 |
|---|---|
| 指向一行 | 选中 |
| 点击一行 | 使用 |
| 点击 `<` 或 `>` | 更改数值，按住可连续更改 |
| 点击数字 | 输入数值 |
| 点击行末的箭头 | 重置已更改的数值 |
| 滚轮或侧边滚动条 | 滚动列表 |
| 右键 | 返回 |
| 标题栏 | 拖动以移动窗口 |
| 右下角 | 拖动以调整窗口大小 |

窗口会在上次的位置以相同大小打开。在列表中，按 Enter 或点击可以展开或收起文件夹，每个文件夹都会保持上次的状态。

菜单打开时角色不会行动。游戏切换画面时（例如任务开始时）菜单会自动关闭。手柄可以在菜单中导航，但只能用 F6 打开菜单。

## 菜单内容 {#whats-in-it}

- **Player：** 无敌、无限冲刺、速度、传送、重生，以及账号拥有的头盔、护甲和披风。
- **Weapons：** 无限弹药、瞬间换弹、补给，玩家所持每把武器的射速、伤害、弹匣、换弹、散布和穿甲，以及基础游戏或已拥有的 DLC 中的任何武器、背包或技能，并带有所选的升级。
- **Stratagems：** 无冷却、无限次数、瞬间呼叫、忽略禁用区域、在光标处投放基础游戏或已拥有的 DLC 中的任意战略配备，以及真实信标（包括增援）。**New stratagem** 以游戏中的某个战略配备为基础制作新的战略配备：名称、代码、图标、冷却、次数、呼叫时间，以及落地时发生的事。其他玩家看到的是作为基础的那个战略配备，下次启动游戏时它会恢复。
- **Vehicles：** 正在驾驶的载具的速度、转向、护甲、不受伤害和机甲无限火箭弹，以及维修和补给。
- **Bots：** 由本机操控的 Helldiver，带有 HUD 栏位，超过四名玩家时则没有栏位。可以对所有机器人或单个机器人下达命令：跟随玩家、原地待命、走到光标处、来到玩家身边、战斗、面向光标、射击、投掷、换弹、像玩家一样输入战略配备代码并把信标投向光标处，以及呼叫战略配备，还可以给它们武器、背包、技能和战略配备。仅限主机，且需在任务中。
- **Spawn：** 当场生成弹药、补给箱和拾取物，以及在光标处放下信标。
- **Enemies：** 停止刷怪、冻结、致盲或眩晕敌人、消灭敌人、生成更多敌人，以及调整遭遇和巡逻的压力。
- **Mission：** 目标列表、完成目标、保护车队和护送对象、快速撤离、跳过等待、在任意任务中使用试炼场修改项、大厅中的玩家、研究样本，以及从飞船开始任意类型的自定义任务，这些任务会给予经验值和样本，且不影响战役。
- **World：** 游戏速度、镜头、HUD、雾、时间和重力，还有声音：音量，以及 **Soundtrack** 页面。该页面可以播放当前画面中的任意音乐曲目、将音乐静音或暂停，并把音乐交还给游戏。
- **Editor：** 每种武器、手雷、背包、战略配备、哨戒炮、地雷、打击、载具、敌人和状态效果的数值。
- **Console：** 开发者命令。
- **Changes：** 所有已启用或已编辑的内容，可以一次全部撤销。

选中某个选项时，菜单底部会显示它的说明。地图上的敌人达到 64 个（含尸体）时停止生成，因为远超这个数量可能导致游戏崩溃。只有主机才能执行的操作在选择时会有提示。

## 它不会做的事 {#what-it-wont-do}

- **不编辑进度。** 修改器的任何页面都不会写入存档。启用它时在任务中获得的东西照常计入，和其他任务一样。[防护](wiki:guardrails)可以让一次启动不计入进度。
- **不提供未拥有的 DLC。** 列表显示全部基础游戏内容、通过游玩解锁的内容，以及已拥有的 DLC。物品只在该次任务中有效，因此不会向存档添加任何东西。
- **不改动共享战争。** 向银河战争报告的命令会被拒绝，结果仍然被拦截（[银河战争](wiki:galactic-war)）。

> [!WARNING]
> 游戏有防篡改检查，触发后玩家会断开网络，直到游戏重启。Obsidian Trainer 只用游戏自身的方式修改受保护的数值，因此不应触发该检查。其他工具和手写脚本可能会触发。

## 与他人一起游戏 {#playing-with-others}

修改器是会话模组，因此在公开大厅中，每个人都需要运行相同的模组或允许会话模组（[联机游戏](wiki:multiplayer)）。如果有不满足这一条件的玩家加入，所有更改都会撤销，修改器的页面也会关闭，直到该玩家离开。之后更改会恢复。在仅限好友或私人大厅中，它始终运行。

**Editor** 中的数值和两个伤害选项都在每位玩家的游戏中运行，因此大家使用相同数值时效果最好。

有两件事要求大厅里只有一名玩家：给予激光瞄准器，因为其他玩家的游戏会在没有初始化的情况下运行它；以及控制台的 `spawn_enemy`，因为它只在一个游戏中加载资源包。

## 保留更改 {#keeping-changes}

更改会持续到游戏关闭。在 **Changes** 中，**Keep edits for later launches** 会保存 **Editor** 中的修改。只要模组的 **保留已保存的修改** 选项开启，这些修改在每次启动时都会恢复。
