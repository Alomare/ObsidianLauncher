## Select a war

**Select** on a war card or on the war screen makes that war the one Play starts, and the button then reads **Selected**. The arrow beside **Play** opens the same choice for every war at once: **Vanilla Main Game** (the official war) first, then the wars this PC hosts and the wars it joined, each with the saves it can boot. Picking **Vanilla Main Game** there goes back to the official war. Wars can only be switched while the game is closed.

## The war save

The first time a war is selected, Obsidian makes a Sandbox save for it, with the tutorials already done. That war always plays on that save, so the rank, XP and unlocks earned in the war stay on it, and the Official save doesn't change. The war save shows in [Saves](app:saves) like any other Sandbox.

A Sandbox needs the Obsidian loader in the game. With nothing deployed, **Play** asks to deploy first, and a game started without the loader, from Steam for example, plays the official war on the Official save.

## In the game

The galaxy map in the game shows the custom war: the fronts, the regions, the running events and the season. Missions work as usual. A completed planet moves the front, and missions on a defense or a home world attack fill that event.

Every war has a separate matchmaking pool. Players only find lobbies of the war they selected, so a squad selects the same war before meeting in the game.

## When the war server is out of reach

The game checks the war every 60 seconds. When no answer comes, because the host closed Obsidian or the network dropped, the game shows the war as offline and keeps trying. Missions finished while the war is offline don't count. The war clock of the host stops whenever the war server is closed, so no defense runs out while nobody can reach the war.
