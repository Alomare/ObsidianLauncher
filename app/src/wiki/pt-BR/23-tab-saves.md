A aba [Saves](app:saves) lista os saves da conta Steam em dois grupos, que se recolhem com um clique na barra:

- Saves **Oficiais**, marcados com uma estrela, são os saves que o jogo usa para a Guerra Galáctica.
- Saves **Sandbox**, marcados com um cubo, são cópias para jogar com mods e para o editor. Eles nunca chegam à Guerra Galáctica.

O save que o jogo carrega na próxima vez tem a etiqueta **Ativo**. Um clique num save mostra os números à direita, com botões para mudar para ele, fazer uma cópia ou duplicá-lo, editar, exportar ou apagar.

Saves Sandbox têm uma caixa de marcar. Saves marcados ganham uma barra embaixo para exportá-los, um zip cada numa pasta, ou apagá-los; o save ativo fica. **Ctrl+A** marca todos os saves Sandbox mostrados, e de novo os desmarca. Saves Oficiais não têm caixa de marcar e são apagados um por vez, depois de digitar o nome.

**Novo** cria um save em branco ou importa um Sandbox de um zip. Um Sandbox precisa do Obsidian Loader no jogo: **Aplicar o carregador** o coloca lá sem nenhum mod.

[Saves](wiki:saves) explica como funcionam os dois tipos de save, os backups e o editor de saves.
