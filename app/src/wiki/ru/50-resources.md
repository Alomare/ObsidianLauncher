Помимо запуска скрипта, мод может заменять ресурсы игры или добавлять новые через список `resources`. Obsidian помещает их в патчи при применении и разбирает конфликты с другими модами по каждому ресурсу.

## Изменённый скрипт игры {#a-changed-game-script}

Скопируйте нужный скрипт игры в папку мода, отредактируйте его и укажите в списке:

```json
"resources": [
  { "type": "lua", "name": "lua/settings/perk_settings", "source": "res/perk_settings.lua" }
]
```

- `type` и `name` задают путь ресурса в игре.
- `source` является обычным Lua в папке мода. Obsidian компилирует его при применении.
- `bytecode` может заменить `source` для файла, который уже является скомпилированным байт-кодом LuaJIT 2.0. Obsidian проверяет заголовок и отклоняет всё остальное.

> [!TIP]
> Хук меняет одну функцию и оставляет остальной скрипт игре, поэтому два мода могут менять один скрипт без конфликта. Для кода предпочитайте [хуки](wiki:loader-api#hooks) и заменяйте скрипт целиком только тогда, когда без этого не обойтись.

## Другие ресурсы {#other-resources}

Текстуры, юниты, материалы и другие типы используют `data`, необработанный ресурс в том виде, в каком его хранит игра:

```json
{ "type": "texture", "name": "units/foo/bar", "data": "res/bar.texture" }
```

Старые моды, преобразованные при импорте, используют такую форму. Чтобы создавать такие файлы с нуля, нужны инструменты, которых для HD1 пока нет.

## Звуковые банки и видео {#streamed-resources}

Звуковые банки (`timpani_bank`) и видео (`bik`) хранят большую часть байтов в файле `.stream` бандла. Передайте эту часть как `stream` рядом с `data`:

```json
{ "type": "timpani_bank", "name": "#e709d0c5697fb286", "bundle": "0e2ec9da60a0f53a",
  "data": "res/menu.timpani_bank", "stream": "res/menu.stream" }
```

Ресурс, который в игре есть на нескольких языках, перечисляет каждый в `variants`, с языковым флагом игры в `lang`. Вариант без `lang` равен 0 и используется для всех языков, у которых нет своего варианта:

```json
{ "type": "timpani_bank", "name": "#f0b3f997d587fb77", "bundle": "f0b3f997d587fb77",
  "variants": [
    { "data": "res/voices.timpani_bank", "stream": "res/voices.stream" },
    { "lang": 256, "data": "res/voices.fr.timpani_bank", "stream": "res/voices.fr.stream" }
  ] }
```

| Язык | `lang` |
|---|---|
| Любой язык без варианта | 0 |
| Японский | 1 |
| Французский | 256 |
| Испанский (Латинская Америка) | 512 |
| Испанский (Испания) | 1024 |
| Португальский (Бразилия) | 2048 |
| Русский | 4096 |
| Итальянский | 8192 |
| Немецкий | 16384 |

При применении Obsidian записывает потоковые части в файл `.stream` рядом с патчем (`<bundle>.patch_0.stream`) в том порядке, в каком их перечисляет патч, так же, как игра раскладывает оригинальные. Изменение звука остаётся на одном ПК, поэтому мод звуковых банков может быть [клиентским](wiki:scopes).

## Отдельные клипы звукового банка {#sound-bank-clips}

Целый банк на всех языках может весить больше гигабайта. Мод, который меняет несколько звуков, может поставлять только эти клипы в `clips`. При применении Obsidian перенаправляет список звуков игры (`timpani_master` в загрузочном бандле) на новые id этих клипов и кладёт клипы под новыми id в небольшой банк Obsidian рядом с банком, который они заменяют. Банки игры остаются как есть:

```json
{ "type": "timpani_bank", "name": "#e0f28740d6c19769",
  "clips": [
    { "clip": "#1111111111111111", "data": "res/rock.clip", "stream": "res/rock.stream" },
    { "clip": "#1111111111111111", "lang": 256, "data": "res/rock.fr.clip", "stream": "res/rock.fr.stream" },
    { "clip": "#2222222222222222", "data": "res/short.clip" }
  ] }
```

- `clip` является id клипа: `#` и 16 шестнадцатеричных цифр. `lang` является языковым флагом из таблицы выше, по умолчанию 0.
- `data` содержит то, что идёт в банк: 68-байтовый заголовок клипа и первую часть звука. `stream` содержит остальное, если оно есть.
- У ресурса с `clips` нет `bundle`: этот небольшой банк попадает в каждый бандл, где есть банк игры, и загружается вместе с ним на языке, выбранном в игре. Не указанные клипы и языки звучат так, как в игре.
- Две строки могут использовать один файл. Моды могут менять разные клипы одного банка, а если два мода меняют один и тот же клип, побеждает тот, что ниже в порядке загрузки. Поверх мода, который заменяет банк целиком, этот банк всё равно применяется, и для неуказанных языков клип звучит так, как в том моде.
- Применение отклоняет клип или язык, которых нет в банке, и файл, заголовок которого не совпадает с размером файла.

Обновление игры считается ожидающим изменением, и новое применение заново читает игру. Применённый патч содержит список звуков (около 0,2 МБ) и новые клипы, причём оригинальный клип для каждого языка исключается там, где этот язык играет другой звук: один звук шага на американском английском, который лежит в двух банках, занимает около 4 МБ на диске.

## Поля {#fields}

| Поле | Что это |
|---|---|
| `type` | Тип ресурса, например `lua` или `texture`, либо `#` и 16 шестнадцатеричных цифр для типа без известного имени |
| `name` | Имя ресурса, например `lua/settings/perk_settings`, либо `#` и 16 шестнадцатеричных цифр |
| `source` | Исходный код Lua для компиляции |
| `bytecode` | Скомпилированный байт-код LuaJIT 2.0 |
| `data` | Необработанный ресурс любого другого типа |
| `stream` | Вместе с `data`: часть ресурса, которую игра читает из файла `.stream` |
| `variants` | Вместо `data`: по записи на язык, каждая с `lang`, `data` и необязательным `stream` |
| `clips` | Вместо `data`: изменяемые клипы звукового банка, каждый с `clip`, `lang`, `data` и необязательным `stream` |
| `bundle` | Бандл, в который попадает ресурс, 16 шестнадцатеричных цифр. Нужен для всех ресурсов, кроме ресурса с `clips` |
| `flags` | Значение, которое бандлы хранят рядом с каждым ресурсом; не указывайте, если его не задал конвертер |
| `when` | Параметры, которые должны иметь эти значения, чтобы ресурс использовался ([Параметры и клавиши](wiki:options-and-keys#options-that-pick-files)) |
| `secondary_scope` | [Дополнительная область](wiki:manifest#hybrid-scopes), к которой относится ресурс (`part` до того, как гибридные области получили это имя) |

## Файлы в дополнительной области {#hybrid-scopes}

В моде с [гибридными областями](wiki:manifest#hybrid-scopes) `"secondary_scope": "<id>"` помещает ресурс в эту дополнительную область. Ресурс выключенной области не применяется, как и при `when`. Ресурс дополнительной клиентской области остаётся у игрока, который его запускает: он не закрывает публичное лобби для игроков без модов, как это делают файлы сессионного мода. В сессионном моде ресурс без дополнительной области следует самой строгой из включённых, поэтому в сессионном или гибридном моде он считается сессионным контентом.

## Ограничения {#limits}

Заменённый ресурс статичен: его нельзя отключить посреди игры. В сессионном моде используйте ресурсы для данных, которые игра читает при запуске, а хуки для поведения. Гибридные области этого не меняют: файлы дополнительной сессионной области остаются в игре в любом лобби, и только применение решает, какие из них попадут в игру.
