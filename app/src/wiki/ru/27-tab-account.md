Вкладка [Аккаунт](app:account), значок человека у правого края верхней панели, связывает Obsidian с аккаунтом GitHub. Всё остальное в Obsidian работает и без него. Галочка на значке означает, что вход выполнен.

## GitHub {#github}

**Войти через GitHub** показывает код и открывает страницу входа GitHub. Введите там код, чтобы завершить вход. Obsidian никогда не видит пароль GitHub.

Список **Доступ** показывает, что GitHub разрешает Obsidian делать, а **Разрешить** запрашивает у GitHub ещё один вид доступа:

| Доступ | Для чего |
|---|---|
| Доступ к публичным репозиториям | Сообщения о проблемах, ответы на отчёты, звёзды модам и предложение мода в Магазин |
| Доступ к Gist | Синхронизация между ПК |
| Доступ к закрытым репозиториям | Моды раннего доступа из закрытых репозиториев, которые может читать аккаунт. GitHub выдаёт этот доступ как чтение и запись во все репозитории, доступные аккаунту, поэтому Obsidian запрашивает его, только когда это разрешено здесь |

**Выйти** заставляет Obsidian забыть аккаунт на этом ПК. Доступ на GitHub остаётся, пока его не отзовёт **Отозвать на GitHub**.

## Отчёты {#reports}

Здесь перечислены проблемы, отправленные кнопкой **Сообщить о проблеме** на странице мода в [Магазине](wiki:tab-store), с модом, состоянием (открыт, закрыт или исправлен) и датой. Число отмечает новые ответы. Щелчок по отчёту показывает переписку, где можно написать и отправить ответ. **Открыть на GitHub** открывает issue в браузере, а **Убрать из списка** убирает его из этого списка, не закрывая на GitHub.

## Синхронизация {#sync}

Синхронизация поддерживает одинаковые профили и настройки внешнего вида на нескольких ПК. Она хранит их в секретном gist в аккаунте GitHub, для чего нужен доступ к Gist.

- **Выгрузить** сохраняет профили и настройки внешнего вида этого ПК в gist.
- **Получить** загружает их на другом ПК. Профили с тем же именем заменяются, а моды из профилей, которых нет в библиотеке, устанавливаются из их репозиториев на GitHub. Моды без репозитория нужно добавить вручную, и Obsidian называет их.
- **Открыть gist** показывает сохранённый файл на GitHub.
