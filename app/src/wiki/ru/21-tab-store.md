[Магазин](app:store) показывает моды, которые устанавливаются одним щелчком, новые первыми. Вверху в отдельном ряду стоит **Obsidian Kit**: Obsidian API, Obsidian Patches и Obsidian Trainer, моды, на которых построен Obsidian.

## Поиск мода {#finding-a-mod}

Ряд над карточками фильтрует по [области](wiki:scopes), сортирует список и оставляет только установленные моды. Поле поиска ищет по названиям и описаниям.

Каждая карточка показывает изображение, название, краткое описание и метки:

| Метка | Значение |
|---|---|
| Серебряный квадрат | **Проверено Obsidian**: мод создан и поддерживается командой Obsidian или тем, кто заслужил её доверие |
| Цветной квадрат | [Область](wiki:scopes) мода |
| **EA** (ранний доступ) | Версия ниже 1.0, ещё в разработке, и последующие версии могут сильно измениться. Моды в закрытых репозиториях тоже относятся к раннему доступу и видны только аккаунту GitHub, у которого есть к ним доступ ([Аккаунт](wiki:tab-account)) |

Зелёный уголок отмечает установленный мод, а жёлтый уголок отмечает мод, для которого в Магазине есть более новая версия.

## Страница мода {#the-page-of-a-mod}

Щелчок по карточке открывает страницу мода: описание, версии с изменениями каждой, параметры, моды, которые ему нужны или которым нужен он, и открытые проблемы на GitHub. Панели справа раскрываются щелчком по заголовку.

**Установить** скачивает с GitHub новейшую версию вместе со всеми нужными ей модами в библиотеку. Мод появляется выключенным: включите его во вкладке [Моды](app:mods) и примените. **Обновить** заменяет установленную копию новейшей версией, а **Удалить** убирает мод из библиотеки.

После входа через GitHub ([Аккаунт](wiki:tab-account)) на странице мода можно также:

- поставить моду звезду на GitHub;
- **Сообщить о проблеме**: форма, которая создаёт issue в репозитории мода от имени аккаунта GitHub, при желании с приложенным отчётом Obsidian. Ответы появляются на вкладке Отчёты в разделе [Аккаунт](app:account).

## Как добавить мод в Магазин {#adding-a-mod-to-the-store}

Магазин читает публичный список, [Obsidian Store Index](https://github.com/Alomare/ObsidianStoreIndex). Мод попадает в Магазин, когда его репозиторий есть в этом списке:

1. Опубликуйте мод в публичном репозитории GitHub с `obsidian.json` в корне (см. [Файл obsidian.json](wiki:manifest)).
2. Выпускайте релизы с тегом из `v` и номера версии, например `v1.0.0`, с приложенным zip мода. Магазин устанавливает новейший стабильный релиз.
3. По желанию добавьте `thumbnail.jpg` (16:9) в корень репозитория и значок, указанный в `image` манифеста. README становится описанием на странице мода.
4. Нажмите **Предложить мод** в Магазине, войдя под аккаунтом GitHub, которому принадлежит репозиторий. Obsidian проверит репозиторий, покажет найденные проблемы и откроет pull request в Store Index на проверку. Подойдёт и pull request или issue, открытые в Store Index вручную.

Индекс пересобирается из релизов каждый час, поэтому новый релиз появляется в Магазине в течение часа. Отметку «Проверено Obsidian» Store Index выдаёт аккаунтам GitHub, которым доверяет: она привязана к аккаунту-владельцу репозитория, а не к авторам, указанным в манифесте.
