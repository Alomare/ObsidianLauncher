A profile remembers which mods are on, the load order, the folders, every option value and key, the [Guardrails](wiki:guardrails) and a color. Switching profiles changes all of that at once. The library of mods is shared, so a mod only takes space once.

The **Profile** button at the top of the [Mods](app:mods) tab opens the profiles. Once there are two or more, the button lists them with their guardrails: a click on one switches to it, and **Manage Profiles** opens the profiles. There a profile can be made, copied, renamed, deleted, or given a picture and a color.

> [!TIP]
> A common setup is one profile for playing with friends and one for solo play. The friends profile can leave out every session mod, which keeps normal matchmaking.

## Color

The color of a profile shows on the **Profile** button and on the switches that are on while the profile is in use, so the active profile is clear at a glance. **Default color** puts the gold back.

## Sharing a profile

**Export** saves the active profile as a `.zip`. The file holds the profile settings and a copy of every enabled mod.

**Import** reads such a file. Each mod in it is installed when it is missing from the library or when the copy in the file is newer. The profile is added under a name that doesn't clash with an existing one. The guardrails that protect the account come along, and Obsidian says so. Blocking session mods from other players in public lobbies stays off, for each player to choose.

A shared profile is the easiest way to give friends the same set of session mods, so the mods run when the group plays together ([Playing online](wiki:multiplayer)).
