### Highlights

#### Added the Saves Tab

Added a **Saves** tab for the Official save and Sandbox saves. A Sandbox plays on a save of its own, in a matchmaking pool of its own and with no war reporting, so the Official save is never written.

#### Added a Save Editor

Added an editor for Sandbox saves with the rank ladder of all 50 insignia, an **Arsenal** board of every item and the DLC owned on Steam. **Deploy Loader** opens a Sandbox without deploying mods.

#### Added Obsidian Commander

Added the **Commander** tab, which hosts custom Galactic Wars on this PC with the war screens and a galactic map inside Obsidian. Other players join over LAN, or over the internet by address and invite code. Nothing reaches the official war.

#### Reworked Play

Changed **Play** to one split button. The arrow opens a choice between the official war on a picked save and a custom war, and the label says Vanilla or Modded and names the war.

#### Added Linux (Beta)

Added Linux as a beta, with an AppImage and a .deb that both update themselves. Commander runs on Linux too, and offers to open the LAN ports in firewalld or ufw.

#### Added Mod Parts

Added parts to mods. The client parts of a hybrid mod keep running in a lobby that isn't cleared, and an option can switch a part off. Mods can also group options under headings and show a live preview of the values.

#### Faster Deploys for Texture Mods

Changed how patches are written: texture mods take about a quarter of the time, and the check of the written patches runs on every core at once.

#### Renamed to Obsidian Launcher

Renamed the app to Obsidian Launcher. The data folder moves from the old name on the first start, and the installer removes the old Obsidian Mod Manager install and keeps the shortcuts.

#### Obsidian API 1.49.0

Updated Obsidian API from 1.39.1 to 1.49.0. Bots find routes around walls, pits and hazards, pick weapons by threat and hold fire when a blast would catch a friend. Mods can hide or carry stratagems, share a cooldown across the squad and remove pickups from the ground.

#### Obsidian Trainer 1.15.0

Updated Obsidian Trainer from 1.13.0 to 1.15.0. The **Player** page sets the move speed while aiming and while reloading, and the **Mission** rows that award progression need a Sandbox save.

### Additions

- Added a mark for modded lobbies in the multiplayer terminal, with the list of mods and filters for them.
- Added the date each save was last played to **Saves**.
- Added Launcher and Commander subtabs to the **Wiki**, each with the **F.A.Q** and **Troubleshooting** on top. The Commander pages cover hosting and sharing a war over LAN, a VPN, a tunnel or port forwarding.
- Added `obsidian commander` commands to the CLI: install the package, host wars without a window and pick the war the next launch plays.
- Added `obsidian.language`, `obsidian.game_text`, `obsidian.ui.list_with` and `obsidian.save_data` to the loader, and a mod id for `obsidian.settings.get`. Game languages beyond the first four now reach mods.

### Changes

- Moved **Deploy** and **Purge** to the **Mods** tab, with a new **Deploy** icon.
- Changed the **Mods** tab: a thumbnail opens a large view and can no longer be changed, the options panel has three columns, a check-all button joins the head, and the bar of checked mods shows icons only.
- Moved **Update All** before the search bar, and a closed folder shows how many mods inside have updates.
- Changed mod options to show each name in a box with the description in a tooltip, with gold slider tracks and a note when a change needs a **Deploy**.
- Added controller button glyphs to **Keys**.
- Changed **Home**: darker and centered, with the slider controls at the top and 30 seconds a slide.
- Changed the text sizes to one scale across the app.
- Changed the mod list a lobby shows to leave client mods out.
- Rewrote the Launcher pages of the **Wiki** in plain language.
- Removed the **Home** button that hid the links.
