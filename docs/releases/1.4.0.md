### Highlights

#### Added Sort Mods

Added **Sort Mods** to the **Mods** tab. It puts the load order in line with what each mod asks for, shows every move with the reason before **Apply**, and offers **Undo**. Mods whose requests clash stay put and are named.

#### Small Deploys for Helldivers 1 Sound Mods

Sound mods made of single clips, such as Audiodiver's Helldivers 1 mods, now deploy as one small patch. One footstep takes a few MB of disk instead of about 3 GB, and a deploy takes seconds.

#### Reworked the Keys Tab

Changed a mod's **Keys** tab to one row per action, with a mouse and keyboard column and a controller column side by side. Mods can name the controller input of an action in their manifest.

#### Updates Without GitHub's Limit

Changed mod update checks to read each mod's release page on GitHub, so they no longer use up GitHub's 60 calls an hour. Added **Check for Updates** to the bar of checked mods, which now floats above the list.

#### Obsidian API 1.39.1

Updated Obsidian API from 1.29.1 to 1.39.1. Bots now get up, revive and heal, use things like a player, fight with chosen weapons, drive vehicles, work terminals, deliver objectives and board the shuttle. The F6 window works with a controller.

#### Obsidian Trainer 1.13.0

Updated Obsidian Trainer from 1.9.2 to 1.13.0. **Custom mission** drops into a real mission, the **Bots** page offers every bot order, and the **Enemies** page shows armor and warns when an enemy aims.

#### Obsidian Patches 1.11.1

Updated Obsidian Patches from 1.11.0 to 1.11.1. The recoil fix holds after every weapon change for every Helldiver, and the war brief that opens by itself on the galaxy map is skipped.

### Additions

- Added a question before **Play** when no mods are deployed, since the game would start vanilla. **Don't ask again** stops it, and **Ask before playing vanilla** in **Settings** brings it back.
- Added a menu of profiles to the profile button, with **Manage Profiles** on top and each profile's color and guardrails.

### Changes

- Redesigned the buttons at the top of the **Mods** tab: the profile became a choice with a chip in the profile color, **Sort Mods** and **Create Folder** became icon buttons, and **Add** became the main green button.
- Replaced the system color picker with one of Obsidian's own, opened beside the swatch, with **Cancel** and **Apply**.
- Removed **Actions** from the bar of checked mods. The menu of a checked row keeps them.
- Removed the update column from the **Mods** list. A newer version shows in gold in the **Version** column, and a mod's details offer **Update to**.
- Removed the resizing of the **Version** and **Scope** columns.
- Enlarged the tab icons and the **Purge** eraser, and made the tab icons follow **Interface scale**.
- Shortened labels such as **Keep mods**, **Move to top**, **Sponsor Project** and **App language**.
- Updated the Wiki for **Sort Mods**, the new buttons, the question before **Play** and the sound deploy.

### Bug Fixes

- Fixed GitHub's limit on bursts of requests showing as "GitHub answered 403" instead of the message about the limit.
