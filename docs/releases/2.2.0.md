### Highlights

#### Faster Sound Mod Deploys

Changed sound mods made of clips to deploy about ten times faster. The Helldivers 2 OST Overhaul deploys in about 2 s instead of 22 s.

#### Obsidian API 1.58.1

Updated Obsidian API from 1.55.1 to 1.58.1. Mods can show words over a Helldiver and split a long settings page into groups, and the Memory Bridge option runs Lua from a developer tool in the running game.

#### Obsidian Patches 1.14.0

Updated Obsidian Patches from 1.12.1 to 1.14.0. Two new fixes start on: one removes the white frame in borderless fullscreen, the other the echo after a Rumbler burst. **Skip login screen** now starts off.

### Changes

- Changed the scope tags in the **Store** to show both scopes of a mod with Hybrid Scopes, split corner to corner.
- Changed the **Update** corner and button in the **Store** to show an up arrow, as in the **Mods** tab.
- Changed the **Obsidian Kit** folder to start expanded in a new profile.

### Bug Fixes

- Fixed **Submit Mod** rewriting the whole list of mods in the pull request to the Store index instead of adding one line.
