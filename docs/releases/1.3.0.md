### Highlights

#### Session Mods Only Wait in Public Lobbies

Changed session mods to run with anyone in friends-only and private lobbies, vanilla players included. Only public lobbies still hold them back until every player allows them. Mods every player needs still apply in any lobby.

#### Blocking Session Mods Is Now Optional

Replaced **Allow other players' session mods in my game** in **Guardrails** with **Block session mods from others in my public lobby**, off by default. Every profile starts with the block off, so playing with other Obsidian players needs no setup.

#### Matchmaking Without Session Mods

Changed matchmaking for players without session mods: their own lobby shows for everyone again, and lobbies of players running session mods are listed beside the vanilla ones and can be joined.

#### Settings Redesigned

Reworked **Settings** into groups, each with a link to the Wiki page that explains it. Patches from other tools now show in a table with their size and date, and **Remove other patches** moves them out of the game folder.

#### Mod Changelogs

Added **Changelogs** to the **About** tab of a mod from GitHub, with every version folded and **Load more** for older ones.

#### Obsidian API 1.29.0

Updated Obsidian API from 1.17.0 to 1.29.0. Mods can now take the camera, place lights, stop time, take screenshots, give custom stratagems their own icons, have bots enter stratagem codes and draw movable panels with tabs.

#### Obsidian Trainer 1.9.2

Updated Obsidian Trainer from 1.6.0 to 1.9.2, adding **Enter a stratagem** to the **Bots** page and a new image in the mod list.

#### Obsidian Patches 1.11.0

Renamed Obsidian QoL to Obsidian Patches and updated it from 1.5.1 to 1.11.0, with recoil and sprint pose fixes and widescreen fixes for the objective list, dialogue boxes and the galaxy map.

### Additions

- Added a link from each scope diamond to the part of the **Scopes** Wiki page that explains it.
- Added `obsidian.ui.solo`, for a mod such as a photo mode to hold back the drawing of every other mod while it has the screen.

### Changes

- Changed **Deploy** to light up when a mod option or key changes, since a deploy is needed to apply it.
- Changed the scope tooltips to name the scope alone, such as **Session**.
- Changed blocking alone, with no mods on, to no longer put the loader in the game.
- Changed the menu icons to have softer edges.

### Bug Fixes

- Fixed the mod list stalling for a second when dragging a mod in a long list, and a delay before a switch flipped.
