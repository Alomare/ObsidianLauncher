### Highlights

#### Expansions, a New Scope

Added the **Expansion** scope, for mods that add their own content beside the normal game, such as an arcade mode. The host starts it once everyone in the lobby runs the same expansion, and those missions stay off the Galactic War.

#### The In-Game Window Moves to Obsidian API

Moved the F6 window into Obsidian API, so it improves with the API's own releases. Each mod's pages sit in a folder of their own, and a key set on Obsidian Trainer before has to be set again in the API's **Keys** tab.

#### Options Changed in Game Come Back to Obsidian

Added a way for mods to put their options on the pause menu's **Mods** page, and Obsidian keeps a change made there for the next launch. Obsidian QoL is the first, with four options.

#### Obsidian API 1.17.0

Updated Obsidian API from 1.9.2 to 1.17.0. Mods can now pick the soundtrack, command bots, make custom stratagems, add settings pages and deal damage that ignores armor.

#### Obsidian Trainer 1.6.0

Updated Obsidian Trainer from 1.3.2 to 1.6.0, adding **Bots** and **Soundtrack** pages, **Make a stratagem**, and a plain description for every option.

#### Obsidian QoL 1.5.1

Updated Obsidian QoL from 1.3.0 to 1.5.1, with plainer option descriptions in every language and four options on the pause menu's **Mods** page.

### Additions

- Added resizable **Version** and **Scope** columns to the mod list: the line at the left of a header moves, a double click resets, and the widths are kept between launches.
- Added `obsidian.expansion.start`, `stop` and `running`, for an expansion to start and end the content.
- Added `obsidian.info(id)` for a mod's name in the game's language, and `always` for `obsidian.keybind`, a key that works in any lobby.

### Changes

- Changed the scope diamonds' colors: expansion yellow, client green, session red, library white and unspecified black.
- Changed the source in the mod details to an icon, with the full link in a tooltip, and the label to **Mod ID**.
- Changed the notification list to drop entries older than a day.
- Changed the **Guardrails** dialog to say "the current profile" instead of the profile name.

### Bug Fixes

- Fixed **Deploy** stopping with "requires Obsidian API" after Obsidian QoL updated to 1.4.0 or later, and on a new install. A mod that gains a requirement now brings it on, and the Obsidian Kit starts with Obsidian API on beside QoL.
- Fixed a crash aboard the ship when the Trainer's **Heavy armor look** was turned on. The look now waits for the next mission.
