### Highlights

#### Expansions, a New Scope

Added the **Expansion** scope, for mods that add their own content beside the normal game, such as an arcade mode. Until that content starts, an expansion counts as a client mod: matchmaking, Galactic War results and Proving Grounds stay as normal, and the expansion's changes to the game stay off. The host starts the content once every player in the lobby runs the same expansion at the same version; otherwise the start is refused and the host is told who is missing it. While the content runs, every game in the lobby follows it, those missions stay off the Galactic War, the lobby can be found by anyone running the same expansion, and a player who joins without it is turned away. The scope diamonds took new colors with it: expansion yellow, client green, session red, library white and unspecified black.

#### The In-Game Window Moves to Obsidian API

Moved the F6 window into Obsidian API, so it improves with the API's own releases instead of waiting for Obsidian. Each mod's pages sit in a folder named after the mod, opened and closed with **Enter** or a click and kept that way between launches, and the title bar names the mod whose page is open. The key guide shows keycaps and what each key does, numbers and text are typed in the row itself, stratagem lists show the stratagem icons, and custom stratagem codes take the arrow keys, **W A S D** or a pad's directions. F6 is now in the **Keys** tab of Obsidian API; a key set on Obsidian Trainer before has to be set again there.

#### Options Changed in Game Come Back to Obsidian

Added a way for mods to put their Obsidian options on the pause menu's **Mods** page. A change made there applies at once, and Obsidian takes it into the profile once the game closes, so the mod details and the next launch show the new value. Obsidian QoL is the first: **Expedite mission end**, **Dynamic solo pause**, **Aim cursor always visible** and **Toggle minimap** can be changed in game, and all nine options are in the mod details again.

#### Obsidian API 1.17.0

Updated Obsidian API from 1.9.2 to 1.17.0. Mods can now:
- pick the soundtrack;
- give bots orders and gear;
- make custom stratagems from the game's own, unlocked free, by rank or by the mod;
- add a page of settings to the pause menu's **Mods** entry;
- hear every hit a player lands, and spare a player from a killing hit;
- trace a line through the world;
- deal damage that ignores armor.

#### Obsidian Trainer 1.6.0

Updated Obsidian Trainer from 1.3.2 to 1.6.0. Added a **Bots** page, a **Soundtrack** page under **World**, and **Make a stratagem** on the **Stratagems** page. Rewrote the wording plainly, gave every option a description, and added stratagem icons to every list. The pages sit in an **Obsidian Trainer** folder in the F6 window.

#### Obsidian QoL 1.5.1

Updated Obsidian QoL from 1.3.0 to 1.5.1, with plainer option descriptions in every language and four options on the pause menu's **Mods** page.

### Additions

- Added resizable **Version** and **Scope** columns to the mod list: the line at the left of a header moves, a double click resets, and the widths are kept between launches.
- Added `obsidian.expansion.start`, `stop` and `running`, for an expansion to start and end the content.
- Added `obsidian.info(id)` for a mod's name in the game's language, and `always` for `obsidian.keybind`, a key that works in any lobby.

### Changes

- Changed the source in the mod details to an icon, with the full link in a tooltip, and the label to **Mod ID**.
- Changed the notification list to drop entries older than a day.
- Changed the **Guardrails** dialog to say "the current profile" instead of the profile name.

### Bug Fixes

- Fixed **Deploy** stopping with "requires Obsidian API" after Obsidian QoL updated to 1.4.0 or later, and on a new install. A mod that gains a requirement now brings it on, and the Obsidian Kit starts with Obsidian API on beside QoL.
- Fixed a crash aboard the ship when the Trainer's **Heavy armor look** was turned on. The look now waits for the next mission.
