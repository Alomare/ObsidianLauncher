### Highlights

#### Faster Deploys

Changed Deploy to keep every patch that would come out the same. Switching one mod on or off no longer rewrites the patches of a large mod such as Upscaled Textures (44 s down to under 1 s), and a full deploy takes about half the time and far less memory.

#### Smaller Texture Mods in English

Changed texture mods to deploy only the texture versions the game reads when it runs in English. Upscaled Textures takes about half the disk space and deploys faster.

#### Added Cancel to Deploy

Added a **Cancel** button to the deploy window. A cancelled deploy removes what it built and leaves the game with the mods, settings and save backups of the last deploy.

#### Obsidian API 1.55.1

Updated Obsidian API from 1.52.0 to 1.55.1. Mods can make custom weapons, helmets, armour, capes and perks from game items, say lines in the text chat and find the stratagem behind a dropped weapon or backpack.

### Additions

- Added a refresh button beside the search in the **Store** tab. New mod releases show without a five minute wait.
- Added a notice when the tamper check of the game leaves the lobby, and loader.log names the guarded value a mod changed. Before, the mission ended with an unexplained Connection lost.

### Changes

- Changed the **Mods** library to open faster.

### Bug Fixes

- Fixed the session mods notice reading as if the mods were off when playing alone in a public lobby.
- Fixed lobby info in a LAN lobby going through Steam instead of the LAN backend.
- Fixed the status bar text sitting low in the bar.
