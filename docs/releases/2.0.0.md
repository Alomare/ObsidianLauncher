### Highlights

#### Added the Store Tab

Added a **Store** tab with the Obsidian Kit and community mods, filters, sorting and a page for each mod. **Install** fetches a mod from GitHub together with the mods it requires.

#### Added the Saves Tab

Added a **Saves** tab for the Official save and Sandbox saves. A Sandbox plays on a separate save, in a separate matchmaking pool and with no war reporting, so the Official save is never written.

#### Added a Save Editor

Added an editor for Sandbox saves with the rank ladder of all 50 insignia, an **Arsenal** board of every item and the DLC owned on Steam. **Deploy Loader** opens a Sandbox without deploying mods.

#### Added Obsidian Commander

Added the **Wars** tab, which hosts custom Galactic Wars on this PC with the war screens and a galactic map inside Obsidian. Other players join over LAN, or over the internet by address and invite code. Nothing reaches the official war.

#### Reworked Play

Changed **Play** to one split button. The arrow opens a choice between the official war and a custom war on a picked save, and the label says Vanilla or Modded and names the war.

#### Added Controller Support

Added controller support across the app. The left stick moves a cursor, the buttons go back, play and switch tabs, and button pictures match Xbox, PlayStation, Nintendo and Steam Deck controllers.

#### Added Change Binds

Added **Change Binds** to the **Keys** tab. Each action takes a key, a mouse button or up to four controller buttons held together, and fires on a tap, double tap, press, long press or release.

#### Added a GitHub Account

Added an **Account** tab to sign in with GitHub. **Report an issue** files an issue for a mod with the Obsidian report attached, replies show in Obsidian, and **Sync** carries profiles to another PC.

#### Added a Versions Tab

Added a **Versions** tab to the details of a mod from GitHub. The tab lists every release by channel and installs any of them, older or newer.

#### Added Linux (Beta)

Added Linux as a beta, with an AppImage and a .deb that both update themselves. Commander runs on Linux too, and offers to open the LAN ports in firewalld or ufw.

#### Added Russian

Added Russian, in the app and in the game. Portuguese and Chinese cover the whole app again, and the **Wiki** is in all four languages.

#### Added Hybrid Scopes

Added hybrid scopes: a mod can run some code with a second scope, such as client code that keeps running in a lobby that isn't cleared. Mods can also group options under headings and show a live preview of the values.

#### Faster Deploys for Texture Mods

Changed how patches are written: texture mods take about a quarter of the time, and the check of the written patches runs on every core at once.

#### Renamed to Obsidian Launcher

Renamed the app to Obsidian Launcher. The data folder moves from the old name on the first start, and the installer removes the old Obsidian Mod Manager install and keeps the shortcuts.

#### Obsidian API 1.52.0

Updated Obsidian API from 1.39.1 to 1.52.0. Bots find routes around hazards, board the shuttle from farther off and use mech rockets and satchels with care, and an option adds a **Script Profiler** with the frame time of each mod.

#### Obsidian Trainer 1.16.1

Updated Obsidian Trainer from 1.13.0 to 1.16.1. The menu comes in Russian and Chinese with item names as the game writes them, and the **Mission** rows that award progression need a Sandbox save.

#### Obsidian Patches 1.12.1

Updated Obsidian Patches from 1.11.1 to 1.12.1. Expedite mission end on Instant no longer crashes the game after a mission that completes a planet, and the options come in Russian.

### Additions

- Added **Size** and **Deployed** columns to the **Mods** list, and a right click on the header shows or hides the columns.
- Added **Ctrl+A** to check every mod shown, **Ctrl+C** to copy the checked mods as a list and **Ctrl+V** to check the mods a pasted list names.
- Added the middle, right, fourth and fifth mouse buttons as keys.
- Added **Public**, **Modded** and **Friends** tabs to the multiplayer terminal, with a mark and a mod list for modded lobbies.
- Added **Report Issue** to the status bar.
- Added Launcher and Commander subtabs to the **Wiki**, each with the **F.A.Q** and **Troubleshooting** on top, and a page for each tab.
- Added `obsidian.language`, `obsidian.game_text`, `obsidian.ui.list_with`, `obsidian.save_data`, `obsidian.war` and `obsidian.profiler` to the loader, and a mod id for `obsidian.settings.get`. Game languages beyond the first four now reach mods.
- Added a loading line on the tabs that wait for the library the first time.

### Changes

- Moved **Deploy** and **Purge** to the **Mods** tab, with a new **Deploy** icon. **Deploy** turns green only for changes that need a deploy.
- Changed the **Mods** tab: a thumbnail opens a large view, the conflict icon sits beside the mod name, the switch of a mod in the game has a green ring, and rows no longer show a tooltip.
- Changed switching a checked mod on or off to switch every checked mod.
- Moved **Update All** before the search bar, and a closed folder shows how many mods inside have updates.
- Changed mod options to show each name in a box with the description in a tooltip, with gold slider tracks and a note when a change needs a **Deploy**.
- Moved the changelogs of a mod from **About** to the **Versions** tab.
- Changed **Home**: centered, with the picture controls at the bottom and 30 seconds a slide.
- Changed **Settings** to show each setting as a row with the control at the right.
- Changed the text sizes to one scale across the app.
- Changed the mod list a lobby shows to leave client mods out, and to scroll instead of stopping at eight mods.
- Changed the **Guardrails** shield to show the state by the fill alone.
- Renamed the command line tool to `obsidian-cli`.
- Changed hooked game functions to take about half the time and garbage per call, and the library refresh to read the deploy record and logs once.
- Changed account sync, downloads and waiting actions to leave the window responsive.
- Rewrote the Launcher pages of the **Wiki** in plain language.
- Removed **Restore Obsidian Kit** from **Settings**: the **Store** installs the Kit, and an empty **Mods** list links to it.
- Removed the **Home** button that hid the links.
