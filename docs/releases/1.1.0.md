### Highlights

#### Mods That Add Units Work Together

Added merging for the game's lists of units. Every mod that adds a new weapon, stratagem or enemy changes the same few lists, so before, the last mod in the load order won and the others' additions were missing in game. Obsidian now combines each mod's additions into one list, so the LAS-288 Pitchfork and other mods like it run side by side.

#### Older Patch-File Mods Import

Added importing for older mods made of `.patch_N` files, such as Tusk Act 4, the LAS-288 Pitchfork and Longer Weapon Range. Each patch is read over the game bundle it changes, and a later file wins a resource, as in the game. A ReShade preset is now named as one instead of "nothing to import".

#### Faster Deploys, With Progress

Reworked how a deploy writes the game's files. Deploys are about three times faster, and a long one, such as a mod that rebuilds a sound bank, shows the progress in a window instead of looking stuck. Deploying when nothing changed no longer rewrites anything: it says the game already has the profile, in about two seconds instead of half a minute. Switching on a mod that rebuilds a sound bank takes a moment instead of ten seconds.

#### Home Art

Added the game's art to **Home**, one picture after another with a slow fade. The small controls at the bottom right go to the picture before or after, and a thin bar shows when the next one comes. With animations off, one picture stays, and the next launch opens on the next.

#### Obsidian API 1.9.2

Updated Obsidian API to 1.9.2. Mods can now read and steer the mission map, play Helldivers from this PC as bots, put perks on a player on top of the main one, and call in a stratagem at a plain position. The names over bots past the fourth player now hide with the HUD.

#### Obsidian QoL 1.3.0

Updated Obsidian QoL to 1.3.0. **Skip war briefs** also skips the brief the galaxy map plays after the war moves, and **Dynamic solo pause**, on by default, freezes a mission while the pause menu is open and nobody else is playing. **Aim cursor always visible** and **Toggle minimap** are new, both off by default.

### Additions

- Added `load` and `load_after` to the manifest, so a mod can ask for a place in the load order when it joins a profile.
- Added `min_obsidian` to the manifest: a mod can name the oldest Obsidian it works with, and an older one asks the player to update.
- Added a line to the **Player** page of Obsidian Trainer, now at 1.3.2, that says whether this launch counts, from **Guardrails**.
- Added `obsidian.wrap`, a hook that keeps running while the lobby isn't cleared, for mods whose replaced files can't be switched off either.

### Changes

- Changed **Guardrails** to a silver button beside **Deploy** and **Play**.
- Changed the startup update prompt to show a **Read the Changelog** button in place of the notes.
- Changed **Update All** to match the buttons beside it, with an icon.
- Added a faint outline to dialogs, menus, tooltips and notifications, and a soft shadow to tooltips and notifications.
- Changed notices and dialogs to fade out the way they came in, and tab underlines to slide in.
- Changed the window to answer clicks faster with large libraries, about twice as fast with 200 mods. After this update, **Deploy** shows changes waiting once.

### Bug Fixes

- Fixed two deploys or purges at once breaking each other. The second now says one is already running.
- Fixed a deploy failing when another tool had changed one of Obsidian's patches. That file is now left to the tool, as **Purge** already did.
- Fixed the top bar running together in a small window at a large interface scale. The tabs and **Play** keep their icons, and their tooltips say what they are.
- Fixed a Nexus download with the version on the last word of the file name, such as "Saber Unlock.v4", importing as a separate mod instead of updating the one you have.
- Fixed checking one mod for updates flashing the whole column of buttons.
- Fixed the command line leaving out mods it can't read without a word. It now names them.
