### Highlights

#### Multiplayer Fix for Hosts

Fixed session mods switching off for the host when a player joined. The player who joined never told the host what they were running, so the host treated them as a player without Obsidian and turned off session mods, while they kept running for the player who joined. Everyone in a lobby needs this version for the fix to work.

#### Messages in the Game's Own Style

Moved Obsidian's messages on the ship and in missions to the game's hint box, with the game's icon and sound, even with hints turned off. Mods can do the same with the new `obsidian.notify`. Obsidian's messages go first, and a mod can have 3 waiting.

#### Proving Grounds Closed While Modded

Closed Proving Grounds, the ranked mode, while session mods are in play. Picking it shows a message, and a trial picked earlier is dropped.

#### Mods Every Player Needs

Added `"every_player"` to `obsidian.json`, for a mod that only works when every player has it, such as one that lets more players into a lobby. It runs only while every other player runs the same version and shared options, switches off alone otherwise with a message in game, and gets a separate matchmaking pool.

#### Sound Bank and Video Mods

Added sound bank and video mods. A resource can carry streamed data and a version per language, and deploy writes the patch's own `.stream` file. Older mods with streamed or per-language resources now import.

#### Sound Bank Clips (Not Yet Tested in Game)

Added `clips` for `timpani_bank` resources, so a mod can ship only the clips it changes and Obsidian rebuilds the bank from the installed game at deploy. This cuts the download from gigabytes to the size of the clips, though the deployed patch stays as big as the bank. Mods that change different clips of one bank now combine.

Rebuilding has been checked against every bank of the game, but no mod in this form has been played yet, so expect rough edges.

### Additions

- Added a Replacing game files section on sound bank clips, and Mods every player needs, to the Wiki.

### Changes

- Changed **Play** to only start the game. It no longer deploys changes that are waiting, so press **Deploy** first.
- Removed the confirmation from **Purge**.
- Changed **Purge** to red when something is deployed and grey when nothing is, with a top bar wave in the same color.
- Changed the top bar wave to one quicker pass that fades out before the tabs.
- Renamed the multiplayer switch to **Allow other modders to affect my game**, and rewrote the tooltip to say what on and off do.
- Changed the **Profiles** dialog to show an icon with a tooltip for that setting, in place of a line of text.
- Moved the folder padlock right before the name, on a faint button that's white when locked and more transparent when unlocked.
- Made notifications darker, so they stand out from the panels under them.
- Changed the lobby filters to **Public (Obsidian Only)** and **Friends (Obsidian Only)**.
- Made `obsidian.session.cleared()`, `obsidian.on_session` and `obsidian.session.guard` answer for the mod that asks.
- Updated Obsidian API to 1.4.1. `api.ui.hint` now goes through `obsidian.notify`.

### Bug Fixes

- Fixed diamonds drawing over the **Notifications** title by removing them. An error's time is orange instead.
